# Expense Classifier
Full-stack expense classification and analytics application with planned machine-learning-assisted categorization, spending insights, and a modern web dashboard.

**Status:** Early development -- an undergraduate CS senior capstone. The current goal is the first walking skeleton: an expense accepted by the frontend, validated by the API, stored in PostgreSQL, and read back out. Machine learning comes after that works.

## Stack

React + TypeScript + Vite on the frontend, FastAPI on the backend, and PostgreSQL through SQLAlchemy and Alembic for persistence, with pytest and Ruff for Python tooling.
